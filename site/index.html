Why LiveBridge

Not a demo that plays a few notes, but everything Live's API allows, with tools built around how producers actually work.

All of Live

168 tools backed by 200 commands: transport, tracks, clips, notes, devices, racks, browser, automation, arrangement, routing, recording. Plus the full Live Object Model for anything else.

Tools that think like a producer

Drum patterns written against the kit's pad names, chords from symbols or Roman numerals with voice leading, arps, basslines, swing, humanize, filter sweeps and LFOs, mixing in dB.

Ears, of a kind

A music-theory check (key, chords, clashes between parts) and audio analysis (LUFS, spectrum, stereo, tempo, key), also against your reference track.

Serum 2, fully controllable

Big VST3 plug-ins expose none of their knobs to Live until you click Configure. LiveBridge exposes up to 128 of them for Claude, no clicking needed.

Splice in the same conversation

Claude searches and downloads with Splice's official MCP server, then LiveBridge puts the sample where you want it: a slot, the arrangement, a Simpler or a drum pad.

Two computers

Claude on your laptop, Live on the studio PC, or the other way round. Discovery on your network, a token on every request, files sent across automatically.

Safe to try

Every change is one undo step. Local-only by default, with a token; LAN mode is opt-in, and Python inside Live can be switched off.

Tested

1,500+ unit tests against a simulated Live on macOS, Windows and Linux, plus end-to-end checks on a real Live 12.4.5.

How it works

A small MIDI Remote Script runs inside Live; an MCP server turns it into tools Claude can use. Nothing else is installed into Live.

Install in a few minutes

You need Ableton Live 12, Python 3.10 or newer, and Claude Code or Claude Desktop. The installer does the rest: the Remote Script, the MCP server, a random token, registration with Claude (and Splice), and the LiveBridge skill.

git clone https://github.com/valentijnh/livebridge-ableton-mcp.git LiveBridge
cd LiveBridge
./installers/install.sh
git clone https://github.com/valentijnh/livebridge-ableton-mcp.git LiveBridge
cd LiveBridge
powershell -ExecutionPolicy Bypass -File installers\install.ps1

No git? Download the zip from the latest release, unzip it into a folder you keep, and run the same installer.

  1. Start Live and pick LiveBridge under Preferences → Link, Tempo & MIDI → Control Surface (Input and Output: None). Live's status bar says LiveBridge … ready on port 9880.
  2. Restart Claude Desktop or open a new Claude Code session.
  3. Ask: “run live_status”, then try “make me a beat”.

FAQ

Which Ableton Live versions does LiveBridge support?

Ableton Live 12, in every edition. It was built and verified against Live 12.4.5 Suite. Live 11 is not supported: the Remote Script is written for the Python 3.11 that Live 12 embeds.

Do I need Max for Live?

No. LiveBridge is a MIDI Remote Script, the same kind of script that drives Push and other controllers, so it runs in every edition of Live 12.

Which AI apps can use LiveBridge?

Claude Code and Claude Desktop, which the installer sets up together with the LiveBridge skill, and any other MCP client that can start a local (stdio) server.

Can Claude hear my music?

Not directly. Claude reads what Live knows (notes, devices, parameters, levels), checks harmony with a music-theory analysis and measures bounced audio: loudness, spectrum, stereo, tempo and key. Your ears still have the final say.

Is LiveBridge free?

Yes, free and open source under the MIT license. You need Ableton Live 12 and a Claude plan; Splice is optional (searching is free, downloads use your Splice credits). If it helps your music, you can buy me a coffee.

Does it work on Windows, and across two computers?

Yes. It runs on macOS and Windows, and Claude and Live can run on two different computers in your network, Mac and PC mixed.

Will it mess up my Live set?

Every change Claude makes is one undo step in Live. Claude asks before deleting or overwriting your material and doesn't start playback or recording unless asked. Save your set yourself: Live's API cannot save.
